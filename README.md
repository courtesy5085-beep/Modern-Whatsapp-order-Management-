# OrderFlow Pro 🚀

Modern WhatsApp Order Management System built with Streamlit.

## ✨ Features
- **Smart Parsing**: Paste WhatsApp messages, auto-extract order details
- **Beautiful UI**: Dark/Light mode, animations, responsive design
- **Real-time Dashboard**: KPIs, revenue charts, status breakdown
- **Advanced Table**: Inline editing with AgGrid
- **Analytics**: Top products, customers, hourly patterns
- **Export**: CSV/Excel export
- **Persistent Storage**: SQLite database

## 🚀 Deploy on Streamlit Cloud
1. Push to GitHub
2. Go to share.streamlit.io
3. Deploy with 1 click

## Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
